
# Минимальный мессенджер — UI-прототип

Интерактивный прототип мессенджера по вашей UI/UX спецификации. Мок-данные, без бэкенда. Светлая тема по умолчанию с переключением на тёмную.

## 1. Дизайн-система и тема
- Настройка цветовых токенов из спецификации: лаймовый акцент (#B6FF2E), оранжевый (#FF7A1A), стерильный минимализм
- Светлая и тёмная тема с переключателем
- Типографика: Inter, размеры H1/H2/Body/Caption по спеку
- Радиусы: 14-16dp карточки, 18-22dp пузыри, 12-14dp кнопки
- Базовые компоненты: Primary/Secondary/Destructive кнопки, инпуты, тосты в стиле спеки

## 2. Онбординг (3 экрана)
- Welcome-экран с логотипом и описанием
- Экран ввода invite-кода
- Экран регистрации (email + ник + пароль)
- Тонкий прогресс-бар сверху, навигация между шагами
- Всё на мок-данных — любой код "принимается"

## 3. Список чатов
- Top bar: поиск, кнопка «Новый чат», меню
- Список чатов с аватарами (инициалы), именем, последним сообщением, временем
- Бейджи непрочитанных (лаймовые)
- Empty state: «Пока нет чатов»
- Мок-данные: 5-7 демо-чатов

## 4. Экран чата 1:1
- Header: имя контакта, статус, кнопки звонка/видео (декоративные)
- Лента сообщений: свои (лаймовый фон) и чужие (surface фон)
- Composer: поле ввода, кнопка прикрепить, кнопка отправки (лайм)
- Долгое нажатие / контекстное меню: copy, reply, delete
- Иконка-щит верификации в заголовке
- Мок-переписка с несколькими сообщениями

## 5. Экран настроек
- Профиль: аватар, ник, email
- Переключатель темы (светлая/тёмная/системная)
- Секция приватности: тоглы «скрыть last seen», «скрыть online»
- Секция хранилища (декоративная)

## 6. Навигация
- Роутинг между экранами: онбординг → список чатов → чат → настройки
- Нижняя навигация или боковое меню (чаты / настройки)
- Плавные переходы между экранами (120-180ms)
